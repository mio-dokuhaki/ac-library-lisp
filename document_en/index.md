## Performance notes

* Put `(declaim (optimize (speed 3) (safety 0)))` at the top of a contest solution once it is
  debugged. Code generated by `define-segtree`, `define-lazy-segtree` and `define-modint` is
  compiled in your file and follows that policy.
* Prefer values that fit in a fixnum (for example two 30-bit numbers packed with `ash`) over
  conses for segment tree monoids: it avoids allocation in the inner loops. See
  `examples/practice2_k.lisp`.
* `read` is convenient but not the fastest reader; for inputs with millions of integers a
  hand-written byte reader is noticeably faster.
